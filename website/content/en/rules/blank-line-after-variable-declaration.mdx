title: blank-line-after-variable-declaration
description: Require a blank line after a variable declaration group when another statement follows.
---

- Rule ID: `tai-kun/blank-line-after-variable-declaration`
- Auto-fix: Yes

Requires one blank line after a group of `const`, `let`, or `var` declarations when a different kind of statement follows. Expression statements that reference the declared variables are treated as part of the same group, so the blank line goes after follow-up processing such as `ready.sort(compare)`.

## Configuration [#configuration]

Add the rule to `lint.rules` in `vite.config.ts` to enable it.

```ts
"tai-kun/blank-line-after-variable-declaration": "error",
```

## Examples [#examples]

### Invalid [#invalid]

```ts
const ready = getItems();

ready.sort(compareNames);
const sorted = [];
```

### Valid [#valid]

```ts
const ready = getItems();
ready.sort(compareNames);

const sorted = [];
```

## Notes [#notes]

- Expression statements that use the declared variables, such as `ready.sort(compare)`, belong to the same group, and blank lines between them are removed.
- Exported variable declarations are also checked.
- Consecutive variable declarations are treated as one group.
- `return` is excluded because `blank-line-before-return` handles it.
