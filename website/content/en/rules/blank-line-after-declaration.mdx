- Rule ID: `tai-kun/blank-line-after-declaration`
- Auto-fix: Yes

Requires one blank line after function, class, interface, type, enum, and namespace declarations when another statement follows.

## Configuration [#configuration]

Add the rule to `lint.rules` in `vite.config.ts` to enable it.

```ts
"tai-kun/blank-line-after-declaration": "error",
```

## Examples [#examples]

### Invalid [#invalid]

```ts
function f() {}
const value = 1;
```

### Valid [#valid]

```ts
function f() {}

const value = 1;
```

## Notes [#notes]

- Overload signatures are excluded.
- Exported declarations are also checked.
- Variable declarations are handled by `blank-line-after-variable-declaration`.
