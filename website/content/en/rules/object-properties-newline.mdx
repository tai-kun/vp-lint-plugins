---
title: object-properties-newline
description: Enforce multiline object literals when they have two or more properties.
---

- Rule ID: `tai-kun/object-properties-newline`
- Auto-fix: Yes

Inserts a line break after `{` when an object literal has two or more properties and the first property starts on the same line as the brace.

## Configuration [#configuration]

Add the rule to `lint.rules` in `vite.config.ts` to enable it.

```ts
"tai-kun/object-properties-newline": "error",
```

## Examples [#examples]

### Invalid [#invalid]

```ts
const value = { a: 1, b: 2 };
```

### Valid [#valid]

```ts
const value = {
  a: 1,
  b: 2,
};
```

## Notes [#notes]

- Sortable objects are skipped because `sort-object-properties` also makes them multiline.
- Use it together with Oxfmt's `objectWrap: "preserve"`.
- Objects with one property are ignored.
